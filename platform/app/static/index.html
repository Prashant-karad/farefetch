How it works

Knock. Pay. Prove.

Three steps between an AI agent and your page. The response below is live from our gateway.

01 · Knock

The agent gets a price, not a page.

Every unpaid request gets HTTP 402 Payment Required with the price, the license terms and a short preview, so the agent can decide if the page is worth it.

402price per readlicense termsfree preview
02 · Pay

It pays from a wallet its owner funded with PayPal.

The owner tops up with PayPal Checkout and sets rules in plain English. Each read costs cents, the publisher gets 90 percent, and a signed pass lets the agent in for the license period.

PayPal Checkoutspending rulessigned passnever charged twice
03 · Prove

Its answer is checked against your license.

Before the answer ships, Fairfetch checks it for copied passages, missing credit and expired passes. Problems are fixed automatically, and you get a signed receipt showing exactly how your work was used.

Proof, not promises

Every step leaves something you can verify.

signed pass

Passes can't be forged.

Each pass is an ES256-signed token for one agent, one page and one time window. The gateway checks it with a public key only.

signed receipt

Receipts anyone can check.

Usage receipts are signed the same way, so a publisher can verify how their work was used without trusting us.

idempotent

Never charged twice.

Retries reuse the same key, payments and PayPal calls are idempotent, and the ledger is append-only.
